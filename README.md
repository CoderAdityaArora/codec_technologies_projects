# PROJECT 1 : AI Resume Parsor

## Overview

AI Resume Parser is a Python-based project that extracts useful information from PDF resumes, such as the candidate's name, email, phone number, skills, and education. The extracted data can be stored in a database for easy searching and analysis.

## Features

* Extract text from PDF resumes
* Identify candidate details
* Extract skills and education
* Easy to extend with Flask and PostgreSQL

## Technologies Used

* Python
* pdfplumber
* spaCy
* Flask
* PostgreSQL

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python AI_resume_parsor.py
```
